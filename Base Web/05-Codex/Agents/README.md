# Agents

## Zweck

Dieser Ordner dokumentiert die projektlokalen Agenten fuer dieses Repo und ihren Ursprung.

## Aktueller Stand

- derzeit ist genau **ein** formaler Projekt-Agent unter `.codex/agents/` eingerichtet
- dieser Agent arbeitet fuer den bestehenden Obsidian-Vault `Base Web/`
- zusaetzlich beschreibt `AGENTS.md` mehrere projektbezogene Agentenrollen fuer konkrete Arbeitsmodi im Website-Projekt

## Dokumentationsregel

Fuer jeden Agenten in diesem Ordner sollte es eine eigene Notiz geben mit:

- Name
- Rolle
- technischer Quelle
- Arbeitsbereich
- Ursprungsprompt
- typischer Nutzung

## Abgrenzung

Nicht jeder Skill oder jede situative Rollenbeschreibung ist automatisch ein formaler Projekt-Agent.

In diesem Ordner werden zwei Dinge dokumentiert:

- formal eingerichtete Projekt-Agenten unter `.codex/agents/`
- klar benannte Agentenrollen, die in `AGENTS.md` fuer wiederkehrende Projektarbeit beschrieben sind
