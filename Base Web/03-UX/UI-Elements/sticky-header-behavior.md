## Verhalten
Der Header bleibt sichtbar und zieht sich nach kurzem Scrollen leicht zusammen.

## Gewuenschte Wirkung
- ruhig
- praezise
- kaum merklich
- ohne Bounce oder Slide-In

## Responsive Hinweis
Auf Mobile muss die Navigation dabei weiterhin stabil benutzbar bleiben.
