# UX

## Zweck

Dieser Bereich dokumentiert die Bedienlogik und Oberflaechenstruktur der Website.

## Aktueller Fokus

- schnelle Orientierung auf der Homepage statt einer Volluebersicht
- klare Navigation ueber die aktiven Hauptbereiche `Live`, `Archive`, `Media` und `About`
- mobile und Desktop-Lesbarkeit ohne Ueberlagerungen oder harte Umbruchfehler
- konsistente Einstiege ueber `PageIntro`, `SectionGrid`, `Card` und `SimplePage`
- ruhige CMS-Anbindung, bei der redaktionelle Inhalte aus `Sanity` kommen koennen, ohne die Oberflaechenlogik zu veraendern

## Juengste Beobachtungen

- die Homepage fuehrt vor allem ueber Schnellzugaenge, kuratierten Kontextblock und zwei nachgelagerte Themenbloecke
- `Live` und `Archive` arbeiten als redaktionelle Uebersichten und nicht als dichte Datenlisten
- `Media` und `About` bleiben bewusst schlank und verteilen Detailtiefe auf Unterseiten
- das eingebettete Studio unter `/studio` gehoert zur Arbeitsoberflaeche, nicht zur oeffentlichen Besucherfuehrung
