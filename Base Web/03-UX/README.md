# UX

## Zweck

Nutzung, Navigation, Einstiege, Lesbarkeit und inhaltliche Fuehrung dokumentieren.

## Aktueller Fokus

- schnelle Orientierung auf der Homepage
- klare Navigation statt ueberladener Einstiegsseite
- mobile und Desktop-Lesbarkeit ohne Textueberlagerungen
- sinnvolle Verteilung von Detailtiefe auf Unterseiten

## Juengste Anpassungen

- Schnellzugaenge oben auf der Homepage
- Entfernen mehrerer Homepage-Sektionen zugunsten eines fokussierteren Einstiegs
- Split-Layouts auf mehreren Unterseiten harmonisiert
- grosse Headlines auf Desktop und Mobile besser kontrolliert

## Beobachtung

- Homepage dient jetzt mehr als Einstieg und weniger als Volluebersicht
- Detailkontext liegt staerker auf Unterseiten
