# Design

## Zweck

Visuelle Prinzipien, Layoutregeln, Typografie und wiederkehrende Gestaltungsentscheidungen.

## Leitlinien

- editorial statt marketinghaft
- reduzierte, glaubwuerdige Typografie
- full-width Layout
- keine dekorativen Divider
- Schwarz, Papier, gedaempfte Tinte und Akzentfarbe ueber CSS-Tokens

## Aktueller Designstand

- grosse condensed Headlines mit kontrollierten Umbruechen
- Split-Layouts fuer zentrale Unterseiten mit verbreiterter linker Headline-Spalte
- reduzierte Homepage mit Schnellzugaengen, schwarzem Kontextblock und kuratierten Inhaltssektionen
