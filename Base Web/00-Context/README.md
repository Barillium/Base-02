# Context

## Zweck

Projektkontext, Zielbild, Rahmenbedingungen und aktuelle Einordnung.

## Aktueller Stand

- Projekt: Website fuer The Base e.V.
- Basis: Next.js App Router, React, TypeScript, Tailwind CSS v4
- Deployment: Cloudflare Workers ueber OpenNext
- Stil: editorial, reduziert, full-width
- Fokus: kulturelles Programm, BOA Bunker of Art, lokale Szene, Archiv, Talents, About

## Laufende Orientierung

- Die Homepage wurde zuletzt deutlich reduziert und kuratiert.
- Live, Label, Media und Shop sind nicht mehr als grosse Homepage-Bloecke praesent.
- Oben auf der Homepage gibt es Schnellzugaenge fuer aktuelle Orientierung.
