# Context

## Zweck

Projektkontext, Zielbild, Rahmenbedingungen und aktuelle Einordnung.

## Aktueller Stand

- Projekt: Website fuer The Base e.V.
- Basis: Next.js App Router, React, TypeScript, Tailwind CSS v4
- Betrieb: framework-nativer Next.js-Workflow fuer lokale Entwicklung und Build
- Stil: editorial, reduziert, full-width
- oeffentlich aktive Bereiche: `Live`, `Archive`, `Media`, `About`
- Fokus: kulturelles Programm, BOA Bunker of Art, lokale Szene, Archiv, Medienproduktion und Vereinskontext
- der bestehende Obsidian-Vault `Base Web/` bleibt das interne Arbeitsgedaechtnis fuer Kontext, Entscheidungen, Aufgaben und Seitenlogik
- ein eingebettetes Sanity Studio unter `/studio` ist im Projekt aktiv und strukturiert redaktionelle Inhalte bereits nach `Setup`, `Live`, `Archive`, `Media` und `About / Fixed Pages`

## Laufende Orientierung

- Die Homepage wurde zuletzt deutlich reduziert und kuratiert.
- Die Navigation und gemeinsame Projektannahmen gehen aktuell nur noch von `Live`, `Archive`, `Media` und `About` aus.
- `Label`, `Talents` und `Shop` bleiben hoechstens als interne oder historische Notizen erhalten, sind aber nicht Teil der aktiven Website-Struktur.
- Oben auf der Homepage gibt es Schnellzugaenge fuer aktuelle Orientierung.
- Homepage, `Live`, `Archive` sowie Teile von `Media` und `About` koennen Inhalte bereits direkt aus `Sanity` lesen und fallen nur bei fehlenden CMS-Daten auf lokale Texte zurueck.
- Im Code existieren weiterhin Legacy-Routen wie `label`, `people` und `shop`, sie gehoeren aber nicht zur aktuellen Navigation oder oeffentlichen Hauptfuehrung.
