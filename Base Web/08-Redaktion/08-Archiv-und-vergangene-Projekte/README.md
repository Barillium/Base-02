# Archiv und vergangene Projekte

Hier werden abgeschlossene Vorhaben, aeltere Fassungen und vergangene Programmlinien sauber abgelegt.

## Hier hinein

- vergangene Projekte mit Kontext
- abgeloeste Entwurfsstaende mit relevantem Verlauf
- archivierte Notizen, die noch Referenzwert haben

## Archivregeln

- nichts Wichtiges still loeschen
- Archivziel und Grund nennen
- Entscheidungshistorie erhalten, wenn sie spaeter noch nuetzlich sein kann
