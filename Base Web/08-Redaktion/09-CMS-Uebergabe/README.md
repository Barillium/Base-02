# CMS-Uebergabe

Dieser Bereich ist die Publishing Queue zwischen redaktioneller Arbeit in `Obsidian` und strukturierter Pflege in `Sanity`.

## Wofuer dieser Bereich da ist

- festhalten, welche Inhalte zur Uebergabe bereit sind
- sichtbar machen, was noch fehlt
- verhindern, dass `Obsidian` zum Doppel-CMS wird

## Ein Inhalt gehoert erst hierhin, wenn

- Status mindestens `approved` ist
- Zielseite oder Zielschema klar ist
- interne Notizen von der publizierbaren Fassung getrennt sind
- Fakten, Namen und Credits ausreichend geklaert sind

## Empfohlene Queue-Logik

- pro uebergabefaehigem Inhalt eine klare Quellnotiz
- kurze Notiz oder Abschnitt mit:
  - Ziel in `Sanity`
  - offener Rest
  - letzter Stand der Uebergabe
- nach erfolgreicher Uebertragung Status in der Quellnotiz auf `transferredToSanity` setzen

## Was nicht hier landen sollte

- allgemeine Ideen ohne Website-Ziel
- finale Pflege von Live-Webtexten parallel zu `Sanity`
- Layoutvorgaben fuer Cards, Hero oder Navigation
