# Seitenentwuerfe

Hier liegen Rohfassungen und Strukturentwuerfe fuer Seiten oder Unterseiten der Website.

## Hier hinein

- Entwuerfe fuer `Home`, `Live`, `Archive`, `Media`, `About`
- Varianten fuer Intros, Langfassungen und Seitenerzaehlungen
- Sammlungen fuer moegliche Seitenmodule, solange sie inhaltlich gedacht sind

## Nicht hier hinein

- fertige Frontend-Komponenten
- genaue Layoutsteuerung
- doppelt gepflegte finale Webkopie ohne Arbeitsnutzen
