# Orte und Kontexte

Dieser Bereich fasst Ortswissen, BOA-Kontext, Bunker-of-Art-Bezuege und thematische Hintergruende zusammen.

## Hier hinein

- Notizen zum BOA Bunker of Art
- ortsbezogene Kontextbausteine
- lokale Bezugssysteme
- Hintergrundmaterial, das mehreren Texten dient

## Nutzen

Diese Notes verhindern, dass Ortskontext immer wieder neu erfunden oder uneinheitlich erzaehlt wird.
