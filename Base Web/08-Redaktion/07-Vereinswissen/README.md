# Vereinswissen

Dieser Bereich sammelt interne Wissensnoten ueber Arbeitsweise, Sprache, Haltung und wiederkehrende organisatorische Zusammenhaenge.

## Hier hinein

- Selbstbeschreibung und Sprachlinien
- Vereinskontext
- Awareness- oder Mitmachen-Hintergrund
- wiederkehrende Antworten auf interne Redaktionsfragen

## Wichtig

Vereinswissen soll Orientierung geben, nicht zu einem unstrukturierten Sammelbecken werden.
