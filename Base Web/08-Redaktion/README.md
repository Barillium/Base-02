# Redaktion

Dieser Bereich macht `Base Web` zu einem redaktionellen Backstage-Arbeitsraum.

Obsidian ist hier fuer Entwuerfe, Recherche, Zusammenhaenge, Versionen und interne Abstimmung da. `Sanity` bleibt das Ziel fuer freigegebene, strukturierte Website-Inhalte.

## Leitprinzip

- Klarheit vor Cleverness
- kleine, reversible Aenderungen
- bestehende Vault-Logik respektieren, bevor etwas umgebaut wird
- keine unnoetigen Notes, Tags oder Metadaten
- nichts Wichtiges still loeschen
- Ambiguitaet markieren statt Fakten erfinden

## Arbeitsweise

1. Zuerst die passende Projekt- oder MOC-Notiz finden.
2. Status und naechsten sinnvollen Stand aktualisieren.
3. Entscheidungen, offene Aufgaben und offene Fragen festhalten.
4. Verwandte Notes verlinken, statt Inhalte zu duplizieren.
5. Aktive Notes auffindbar halten und alte Inhalte explizit archivieren.

## Was hier bewusst bleibt

- Rohtexte
- Langfassungen
- Interview- und Recherchematerial
- Themencluster
- Strukturentwuerfe
- interne Versionen
- Begruendungen, warum etwas so formuliert oder geordnet wurde

## Was hier bewusst nicht gepflegt werden soll

- finale Layoutsteuerung der Website
- Hero-, Card- oder Formularkonfigurationen fuer das Frontend
- doppelt gepflegte Live-Webtexte ohne redaktionellen Mehrwert
- technische CMS-Felder, die nur fuer die Ausspielung existieren
