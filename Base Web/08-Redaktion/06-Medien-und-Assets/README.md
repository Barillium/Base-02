# Medien und Assets

Hier werden Bildmaterial, Credits, Medienhinweise und redaktionelle Asset-Notizen gesammelt.

## Hier hinein

- Bildlisten mit Kontext
- Credit-Notizen
- Asset-Luecken
- Hinweise fuer Pressebilder, Poster oder Mitschnitte

## Nicht hier hinein

- finale Dateiablagen als Ersatz fuer Asset-Storage
- technische Bildoptimierung oder Build-Details
